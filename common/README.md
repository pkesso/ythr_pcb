# common — shared generator and libraries

Every board is generated by a Python script (`<board>/gen_<board>.py`) from a circuit description;
the KiCad files are outputs, never edited by hand. The decisions behind the circuit are in
[../README.md](../README.md).

```
ythr_pcb/
  tools/            kicad_cli.py, kicad_gen.py, kicad_checks.py, repo_check.py (KiCad helpers); jlcpcb_rules.py
                    (JLCPCB limits into a project), gerber.py (validated fabrication zip), views.py (renders,
                    height map), ngspice.py (KiCad's ngspice), drill_template.py (A4 1:1 lid drill template)
  parts/            availability.json: stock, prices, lifecycle and alternates of the parts (checked by hand)
  common/
    lib/            PedalLib.pretty (footprints) + PedalLib.kicad_sym (symbols) used by all boards
    templates/      enclosure board templates (Type_Z-77_1590N1: Gate + Comp), copied into the project
    gen/
      libs.py       builds lib/: snapshot of KiCad library parts + own footprints (PEC11R, RJ45 Ckmtw, holes,
                    wire pads) and symbols (7-segment digit, common anode)
      parts.py      part catalogue: symbol, footprint, value, LCSC number
      design.py     Design / Part, and the blocks: bus (RJ45, TVS, pull-ups), mcp, encoder, indicator, switch
      layout.py     placement helpers for the 50 x 65 mm pedals
      outline.py    board outlines from enclosure templates (templates/*.kicad_pcb): Edge.Cuts kept as they are,
                    router / label keep-outs outside the contour and around its holes
      schematic.py  schematic writer (one local label per pin, symbols in groups)
      router.py     grid A* (0.125 mm, turn costs, vias) and copper rasterisation
      negotiate.py  negotiated-congestion routing (PathFinder) + GND vias / stitching
      fastroute.py  the same search compiled with Numba, conflicting nets rerouted on all cores
      board.py      board writer: footprints, tracks, GND zones (both layers), silkscreen, BOM/CPL
      build.py      runs everything for one board, then ERC, DRC (with schematic parity) and renders
  effect/ gain-compressor/ echo/ rever/ presets/ main/     one KiCad project per board
  tests/            board and fabrication tests (unittest)
```

## Running

```bash
.venv/Scripts/python -m gen.libs                 # from common/: rebuild the libraries (rarely needed)
.venv/Scripts/python effect/gen_effect.py         # one board: schematic, routing, board, BOM/CPL, ERC/DRC, renders
```

Options of the board scripts: `--reroute` (ignore the cached routing in `routing.pkl`), `--no-checks`.

Outputs per board (`<board>/`): `<name>.kicad_sch`, `<name>.kicad_pcb`, `<name>.kicad_pro` (created only when
missing — KiCad settings live there), `fp-lib-table`, `sym-lib-table`, `<name>_bom.csv` / `<name>_cpl.csv`
(JLCPCB), `<name>_top.png` / `<name>_bottom.png` (renders), `routing.pkl` (routing cache, keyed by placement and
nets).

## Tests

```bash
.venv/Scripts/python -m unittest discover -s tests -t tests -v          # all, ~40 s (from the repo root)
.venv/Scripts/python -m unittest discover -s tests -t tests -k Fab      # one group
```

`tests/test_boards.py` checks every board (Effect, Gate+Comp, Echo, Reverb, Presets, Main):

## How the board is made

- **Footprints** are copied whole from the library snapshot (no `lib_footprint_mismatch`); fields mirror the
  symbols (Reference, Value, Footprint, Datasheet, Description, LCSC), so schematic parity is clean.
- **UUIDs** are keyed by identity (reference, pad, segment geometry, label position), so regenerating gives
  identical files and small changes give small diffs.
- **Routing**: every net except GND is routed on a 0.125 mm grid (0.25 mm tracks, 0.2 mm clearance, 0.6/0.3 mm
  vias), top layer preferred. Nets are rerouted with growing congestion costs until no track runs inside another
  net's clearance. GND: before the signals are routed, each SMD GND pad gets a short track to a reserved via;
  these vias and all through-hole GND pads are then joined by GND tracks (bottom layer preferred), so ground
  does not depend on the zones staying in one piece. Both layers carry a GND zone, with stitching vias where
  there is room.
- **Speed**: the A* search runs as Numba-compiled code (`gen/fastroute.py`); from the second iteration on, the
  nets in conflict (12 or more) are rerouted in parallel worker processes against the same congestion snapshot,
  and the results are applied in net order, so the routing stays deterministic. A pedal routes in seconds
  (17-41 s for a full build with checks and renders), Main in ~4.5 min (150 iterations: `Design.route_iterations`).
  Each worker holds its own search buffers (~0.45 GB on Main), so their number is capped by `MEM_BUDGET` (4 GB) in
  `gen/fastroute.py`. When conflicts remain, the routing is repeated with other via costs and the attempt with
  the fewest problem nets is kept. `PEDALGEN_SLOW=1` selects the pure-Python reference implementation in
  `gen/negotiate.py`.
- **Silkscreen**: reference designators and function labels are placed around each part's courtyard, clear of
  pads, holes, other text and the board edge (1.0 mm text); a label that finds no room goes to the Fab layer.
